## Project Overview

This repository contains the complete group and individual deliverables for **Assignment 2 (Situated Learning Assignment)**:

1. **Group Gaming Simulation (`Question1_Group154.ipynb`):**  
   A Python implementation of a custom 3×3 mini-chess game featuring Soldiers/Pawns (`S`) and Horses/Knights (`H`), built using the **Minimax algorithm** with a custom static evaluation function and interactive human-vs-AI gameplay.
2. **Individual Knowledge Representation & Reasoning (`2025AGXXXXX_StudentX.pdf`):**  
   Five independent Situated Learning reports applying Propositional Logic, Predicate Logic, and rule-based Knowledge Bases (facts and inference rules) to real-world organizational workflows.
